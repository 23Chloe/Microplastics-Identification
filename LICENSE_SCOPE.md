# Project license scope

The third-party model directories are distributed under the licenses listed in
`THIRD_PARTY_NOTICES.md` and their local license files.

The repository does not yet assign an open-source license to the project-owned
`pipeline/`, `scripts/`, documentation, dataset metadata, or trained
checkpoints. Until the copyright holders select and add a root license, those
materials remain without an express reuse grant. This is an explicit release
boundary, not an open-source license.

Before the stable release, the copyright holders must choose the license for
project-owned material and state whether trained checkpoints and dataset
metadata are covered by the same terms or separate terms.
